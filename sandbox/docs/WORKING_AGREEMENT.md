# ข้อตกลงการทำงาน (Sandbox)

อัปเดต: 2026-07-13

## โหมดเริ่มต้น = Sandbox

หลังคุยและตกลงงาน:

| การกระทำ | ค่าเริ่มต้น |
|----------|-------------|
| สร้าง/แก้ไฟล์ใน `sandbox/` | ทำได้หลังตกลง (ไม่ถามซ้ำทุกไฟล์) |
| แก้ไฟล์ production (`application/` ฯลฯ) | ต้องมีคำสั่งชัด |
| รัน SQL บน DB จริง | ต้องมีคำสั่งชัด |
| ลบไฟล์ | ต้องมีคำสั่งชัด |

## คำสั่งที่ใช้บ่อย

- `เริ่มใน sandbox` — สร้างไฟล์ร่างตามที่ตกลง
- `review sandbox` — สรุปสิ่งที่มีใน sandbox
- `โปรโมทเข้า production` — copy/apply เข้า path จริง (ระบุไฟล์)
- `รัน SQL บน DB จริง` — อนุญาต execute (ระบุสคริปต์)

## หมายเหตุสภาพแวดล้อม

- Workspace ปัจจุบันชี้ไปที่เครื่อง/โฟลเดอร์ที่ IIS ใช้จริงได้
- มีสำเนาเก่า: `c:\inetpub\bnyfoodproduct - Copy` (ไม่ได้ใช้เป็น sandbox หลักของงานนี้)
- Sandbox หลักของงานใหม่: `c:\inetpub\bnyfoodproduct\sandbox`
